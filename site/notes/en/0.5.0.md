## 0.5 — Security

First step on the road to 1.0 ([roadmap](https://github.com/LucasLomiento/resenha/blob/main/docs/ROADMAP.md)).

- **Screen audio no longer carries your Discord call.** By default it includes sound from every app except voice apps (Discord, Vesktop, TeamSpeak, Mumble, Zoom, Teams…). You can also pick just the apps you want when sharing (Linux).
- **Your login no longer shows up in any log.** The session code went in the connection address, which gets recorded in the server logs; now it's sent inside the already open connection.
- **Saved login encrypted in the system keyring** on Hyprland and other environments without KDE/GNOME too (before, it was stored in plain text).
- **Notifications can hide the message text** (Settings → App), handy when your screen is being shared.
- **Locked-down window:** the app's page can only talk to the Resenha server, and the main process only answers its own window.
