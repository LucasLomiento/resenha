## 1.3.0: bring a Discord server over from a screenshot, and a resizable channel list

- **Bring it from Discord:** take a screenshot of a Discord server's channel list and Resenha builds the same thing: categories, text and voice channels, in the same order, with the emojis. Before creating, you can check it, change the type, rename, drop what you don't want or strip the emojis.
  - **New server:** in the "+" of the server column, "Bring it from Discord". The server starts with the name from the screenshot and only its channels.
  - **In an existing server:** server menu → "Import channels from Discord". The channels go to the end of the list.
  - Tip: screenshot just the channel column, with the categories expanded. The screenshot is read by a Cloudflare AI; it isn't stored.
- **Wider or narrower channel list:** hover over the right edge of the list and drag. Double-click goes back to the normal size.
- **What's new:** the "What's new" in the update notice now opens the Resenha website, right at the new version.
