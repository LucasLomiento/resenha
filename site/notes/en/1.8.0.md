## 1.8.0: rooms through Cloudflare

- **Rooms through Cloudflare:** the Resenha owner can set a voice channel to go through Cloudflare instead of directly between PCs. Just right-click the room and pick "Route through Cloudflare". In a room like that, voice, camera and screen share go through Cloudflare's servers. The connection works on any network, and nobody's IP shows up to the others. A cloud next to the name shows which rooms are set up like this. You can turn it on and off mid-call without anyone dropping. It uses the same free monthly quota. If that runs out, the room goes back to direct on its own and lets you know.
